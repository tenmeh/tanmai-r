# Convert a UCI score into a single centipawn number

Convert a UCI score into a single centipawn number

## Usage

``` r
score_to_cp(cp, mate)
```

## Arguments

- cp:

  Centipawn score, or `NA`.

- mate:

  Moves-to-mate score, or `NA`.

## Value

A centipawn-scaled value from the side-to-move's point of view.
