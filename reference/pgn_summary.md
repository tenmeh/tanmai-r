# A one-line description of an imported game

A one-line description of an imported game

## Usage

``` r
pgn_summary(headers, n_moves)
```

## Arguments

- headers:

  Headers from
  [`game_from_pgn()`](https://tenmeh.github.io/tanmai-r/reference/game_from_pgn.md).

- n_moves:

  Number of plies.

## Value

A single string, or `NULL` when the headers say nothing useful.
