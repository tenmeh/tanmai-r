# Calibrate a template library from a starting-position board

Calibrate a template library from a starting-position board

## Usage

``` r
build_from_start_position(squares)
```

## Arguments

- squares:

  A list of 64 square images of the standard starting position (white on
  bottom, row-major top-first).

## Value

A template library list with `pieces` and `empty_threshold`.
